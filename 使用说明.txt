========================================
  娅娅 · 桌面宠物   ——  使用说明
========================================

【怎么开始】
1. 把整个文件夹解压到任意位置（桌面、D 盘都行；不建议放 C:\Program Files，
   那里普通程序没有写权限，她记不住你们的进度）
2. 双击「娅娅桌面宠物.exe」
3. 她就出现在屏幕右下角，并且会自己在桌面建一个快捷方式，以后双击那个图标就行

【需要什么】
Windows 7 及以上。程序用的是系统自带的 .NET Framework 4.x
（Win 8 / 10 / 11 都自带，不用另外安装任何东西，也不用联网）

【怎么跟她玩】
· 点一下        = 摸摸头（蹦一下 + 飘爱心 + 好感度 +1）
· 双击 / 右键   = 弹出菜单（投喂蛋糕、找话题、做动作、走两步、换姿势、设置…）
· 快速连点      = 她会假装生气
· 拖           = 随手拖到桌面任意位置，松手记住新家
· 鼠标靠近      = 她会注意到你
· 不理她        = 3 分钟开始找你，5 分钟自己走开，8 分钟打瞌睡，12 分钟睡着
· 托盘图标      = 让她歇会儿 / 叫回来 / 设置 / 退出

【和她聊天】
双击她 → 「和我聊天」，打字回车即可。两种方式（设置里切换）：
· 本地词库（默认）：完全离线，不联网不花钱，她按关键词回你
· AI 对话：想真聊就填一个 API Key（默认走 DeepSeek，任何 OpenAI 兼容接口都能用）
  Key 用 Windows 加密后只存在你本机，别人拿到文件也解不开

【她记了什么】
只记：名字、好感度、位置、大小、设置（存在程序旁边的 data 文件夹里）。
不记录你打了什么字，也不读你的文件。本地词库模式全程不联网。

【想改她】
· 改名字：设置里直接改
· 改台词：用记事本打开 content\lines.json，找到对应的分类往里加句子就行
· 换形象：把新的三视图给我，我可以重新切图

【不想要了怎么卸】
1. 托盘图标右键 → 退出
2. 删掉这个文件夹
3. 删掉桌面的快捷方式
4. （如果开过「开机自动启动」）删除注册表这一项：
   HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
   里面的 YayaDesktopPet

【如果 Windows 拦你】
这个程序没有买数字签名，第一次运行可能弹「Windows 已保护你的电脑」：
点「更多信息」→「仍要运行」即可。
如果是从压缩包解压出来的，可以先右键压缩包 → 属性 → 勾选「解除锁定」→ 确定，再解压。

【菜单都是什么意思】
摸摸头      点一下也行
投喂蛋糕    好感度 +3，一天最多三块
和我聊天    打开聊天窗
找个话题    她主动抛个话题
做个动作    跳/转圈/挥手/跳舞/伸懒腰/回头/坐下
走两步      走到桌面别处
自动走动    开关（默认开，她每 15–30 秒自己遛一圈）
换个姿势    正面 / 侧面 / 背面
设置        名字、聊天方式、API Key、她的大小、自动走动、开机自启
让我歇会儿  她躲起来，点托盘图标叫回来

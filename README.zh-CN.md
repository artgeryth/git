# 娅娅 · 桌面宠物

一个**住在 Windows 桌面上的女孩子**：透明无边框、永远置顶，会在桌面上溜达、被你拖动、点她会有反应、能投喂、能陪你聊天。

和 `学习系统` 里那只**不是同一个东西**——那只挂在网页里、管你学习；这只是独立软件，**不管你学习**，就是陪你闲聊。两边共用同一套立绘（娅娅），代码和进度互不相干。

### 👉 [**点这里下载（Windows）**](https://github.com/artgeryth/git/releases/latest) · [所有版本](https://github.com/artgeryth/git/releases)

下载 **`-win.zip`** 那个文件 → 解压到任意位置（**别放 `C:\Program Files`**）→ 双击 `娅娅桌面宠物.exe`。
Windows 7 及以上 · 免安装 · 不需要装任何运行库 · 本地聊天模式全程不联网。

## 一、怎么用

1. 双击 **`娅娅桌面宠物.exe`**（第一次运行会自动在桌面创建快捷方式，以后双击桌面图标就行）
2. 她就出现在屏幕右下角：**双击她**（或右键点她）会弹出菜单

> 没编译过？先跑一次 `tools\build.bat`（用 Windows 自带的编译器，**不需要装任何东西**）。

**退出**：托盘图标（右下角通知区）右键 → 退出；或者设置窗里的「退出」。
关掉她不会丢了好感度，一切记在 `data\state.json`。

## 二、她能干什么

| 操作 | 反应 |
|---|---|
| **点一下** | **摸摸头**：蹦一下 + 飘爱心 + 台词 + 好感度 +1（2.5 秒内不重复计数） |
| **双击** | **召唤菜单**（右键点她也一样） |
| **快速连点** | 1.2 秒内点 4 下以上 → 「喂喂喂，手指头不累吗」+ 摇晃 + 假装生气 |
| **拖动** | 随手拖到桌面任意位置，松手记住新家（下次开机还在那儿） |
| **鼠标靠近她** | 她会注意到你并蹦一下（90 秒冷却，不会烦你） |
| **右键 / 双击** | 弹出菜单：摸摸头 · 投喂蛋糕 · 和我聊天 · 找个话题 · 做个动作 · 走两步 · 自动走动 · 换个姿势 · 设置 · 让我歇会儿 |
| **做个动作** | 跳一下 / 转个圈 / 挥手 / 跳舞 / 伸懒腰 / 回头 / 坐下，各有动画和台词 |
| **走两步 / 自动走动** | 走到桌面别处（侧面姿势 + 朝向翻转 + 走路颠簸）；开了自动走动她每 15–30 秒自己遛一圈 |
| **投喂蛋糕** | 蛋糕落下 + 爱心 + 好感度 +3（每天最多 3 块，第 4 块会说吃不下了） |
| **和我聊天** | 打开聊天窗，打字跟她说话（见第四节） |
| **让我歇会儿** | 她下班躲起来，托盘图标点一下就能叫回来 |
| **她会记住你** | 跟她说「记住：我在备考」她就记下了（AI 模式下她也会自己学）。问「你记得什么」看她记住了啥，说「清空记忆」全忘掉 |
| **小游戏** | 菜单里选「陪我猜拳 / 陪我猜数字」，或者在聊天里直接说。她会认真玩，也会嘴硬 |
| **会管你作息** | 连续用电脑 50 分钟她会赶你起来活动；凌晨 1–5 点还醒着她会催你睡。判断依据只有系统的「最后输入时间」，不记录你打了什么 |
| **知道今天是什么日子** | 元旦、跨年夜、情人节、儿童节、国庆、万圣夜、圣诞、春节、中秋，还有**你的生日**（跟她说「我的生日是 3 月 15 日」） |
| **互动也能现场生成**（AI 模式） | 接上 API 后，摸头、投喂、做动作不再只说词库里那几句固定的——她会现场想一句。本地台词仍然先说，所以不会卡 |

**透明的地方鼠标能点穿**：只有她身上（和头上的气泡）会挡住鼠标，窗口其余部分是空的，不耽误你点桌面和别的软件。点她**不会抢走你正在打字的窗口的焦点**。

### 按你的状态说话（挂机分级）

| 你多久没碰键鼠 | 她的反应 |
|---|---|
| 在用电脑 | 隔 1.7–4 分钟随口嘀咕一句（闲聊 / 吐槽 / 报自己刚才在干嘛） |
| **3 分钟** | 开始找你：「你是不是把我忘了？」 |
| **5 分钟** | 抱怨无聊，然后**自己走开**去桌面别处 |
| **8 分钟** | 困了，换成侧面姿势打瞌睡（头顶冒 Z） |
| **12 分钟** | 睡熟，说梦话 |
| 你一碰键鼠 | 立刻醒：「啊！我没睡！」 |

另外**按时间问候**（早上 / 下午 / 晚上 / 深夜各一套词），你好几天没开电脑她会说想你。

### 好感度

点一下 +1、投喂 +3、摸摸头 +1、模考那种事没有了。等级：
**刚认识 → 有点熟了 → 朋友 → 好朋友 → 无话不谈**（0 / 15 / 40 / 80 / 140）。
升级会庆祝，并解锁一部分只有熟了才会说的台词（词库里标了 `minLv`）。

### 调她的大小（设置里的滑杆）

**设置 → 桌面上她的大小**，拖滑杆即可，范围 **40% ~ 250%**：

- **所见即所得**：拖动时她当场变大变小，下面的字会实时告诉你「她大约 XXX 像素高（屏幕高度的百分之几）」
- **点「保存」才记住**；点「取消」或直接关掉设置窗，会恢复成打开设置前的样子
- 等级 / 名字 / 聊天方式等其他设置不受影响

默认 100% 大约是屏幕高度的四分之一（150% 缩放的 2560×1600 屏上是 420 像素高）。
她变大时头顶的气泡区会跟着抬高，不会贴着脸说话；位置也会自动收进屏幕，不会被拖丢。

## 三、聊天：两种模式，设置里自己挑

打开 **设置** → 聊天方式：

### ① 本地词库（默认，推荐日常用）
- **离线、零配置、不花钱**，不需要任何账号
- 你打字，她按**关键词 + 当前好感度**从 500 多条台词里挑一句回你，有 18% 概率再补一句（所以有时她会连说两句）
- 覆盖问候、情绪、天气、游戏、追剧、音乐、吃、上班、周末、夸她/损她、要她唱歌讲笑话……接不上话时会可爱地糊弄过去并反问你

### ② AI 对话（想真的聊天时开）
- 填 **API Key** 就能变成真·大模型聊天，她能记住最近 12 轮上下文
- 默认接 **DeepSeek**（`https://api.deepseek.com/v1/chat/completions`，模型 `deepseek-chat`），
  **任何 OpenAI 兼容接口都能用**：通义、Kimi、OpenAI、本地 Ollama 都行，改「接口地址」和「模型」即可
- 设置里有 **测试连接** 按钮，不用瞎猜为什么连不上
- 「性格补充」里写的设定会拼进她的系统提示词（比如你想让她更冷淡一点、或者改用某种说话风格）
- **没填 Key 就选 AI** 时她不会哑掉：会提示你，并临时用本地词库继续陪你聊
- AI 调用失败（断网/欠费/Key 错）她会说「走神了」那类话，**不会把你的聊天记录发到别处**——只发给你填的那个接口

> **Key 怎么存的**：用 Windows DPAPI 按当前用户加密后写进 `data\state.json`，换用户/换电脑解不开。明文只在内存里出现。

### ③ 聊天里还能做这些（两种模式都认）

| 你说 | 她会 |
|---|---|
| `猜拳` | 陪你玩石头剪刀布（说 `rock paper scissors` 也认） |
| `猜数字` | 想一个 1–100 的数让你猜，说大了还是小了（`guess a number` 也认） |
| `不玩了` | 结束正在玩的小游戏 |
| `记住：我在备考` | 记下来，以后聊天自然地带出来 |
| `你记得什么` | 把记住的事念给你听 |
| `清空记忆` | 全部忘掉 |
| `我的生日是 3 月 15 日` | 记住你的生日，到那天她会说点特别的 |

记忆最多存 30 条，只存在你自己的 `data` 目录里，不会上传到任何地方。

## 四、改词库（这是日常最常改的东西）

台词**不在代码里**，全在 `content\lines.json`：

```json
"categories": {
  "click":     ["诶嘿～", {"text": "更熟以后才说的话", "minLv": 3}],
  "chat_food": ["想吃火锅，但得有人陪我一起涮才行。"]
}
```

- 想加自己的话：直接往对应分类里加字符串
- `{"text": "...", "minLv": 3}` = 好感度 3 级以后才会说
- 可用占位符：`{name}`（她的名字）、`{lvName}`（当前等级名）、`{days}`（多少天没见）、`{topic}`（随机话题）
- `chat_keywords` 决定「你打什么词 → 命中哪个分类」；引擎把所有关键词按**长度从长到短**匹配，先命中的赢（所以「睡不着」会赢过「睡了」）
- `chat_fallback` 是关键词一个都没命中时依次尝试的分类，`typing` / `error` 是 AI 模式的等待语和失败语

改完**不用重新编译**，`lines.json` 是运行时读的，重开软件就生效。

**素材源文件**（`content\_*.json`）和合并脚本：

```bat
node tools\build-lines.mjs      :: 把 _meta / _keywords / _env1 / _env2 / _chat1 / _chat2 合并成 lines.json
```
合并时它会检查：关键词指向的分类存不存在、代码要用的分类缺没缺（缺了直接报错退出，不会写出一份半成品）。

### 换形象

立绘是四张透明 PNG：`content\sprites\pet-front.png / pet-side.png / pet-back.png / pet-avatar.png`。
换一套直接把新图覆盖进去即可（尺寸不必一样，程序按高度等比缩放；`pet-avatar.png` 同时用作托盘图标）。

## 六、排障

| 现象 | 怎么办 |
|---|---|
| 她不见了 | 托盘图标（通知区）双击叫回来；或再双击一次 exe（第二个实例会把第一个叫出来，不会开两个） |
| 她不说话 | 看 `data\pet.log`；`content\lines.json` 读不出来时她会提示你，日志里也有原因 |
| 想看她这一帧画了什么 | `娅娅桌面宠物.exe --dump "C:\路径\frame.png" --dump-after 1600`（透明底 PNG，能直接看到气泡和姿势） |
| 想一次跑完所有检查 | 双击 `tools\selftest.bat`：词库完整性、关键词路由、等级递进、禁词扫描、聊天全链路、7 个动作 + 睡觉 + 投喂 + 菜单逐帧出图 |
| 她只在原地做走路动画、不挪位置 | 走动那一帧必须**同时**改内部坐标 `PetX` 和窗口 `Location`（见 `PetWindow.Tick` 的走动分支）。`--selftest` 里有专门一节会对比 1.5 秒前后的窗口 Left，改坏了会直接报 ✗ |
| 换了图 / 改了台词不生效 | 台词重开即可；换精灵图也是重开（图片是启动时读的） |
| 想看她的坐标 / 走动状态 | 设环境变量 `YAYA_DEBUG=1` 再启动，`pet.log` 里每 5 秒会写一行心跳（窗口位置、内部坐标、是否在走动/拖动） |
| 她看起来「只剩一半」/被放大 | 这是 **DPI 缩放把绘制放大 1.5 倍**的经典坑，已在 `Sprite.LoadPng` + `LayeredWindow.EnsureBuffer` 里修好。若再出现，用 `tools\bbox.exe` 比一下 `--dump` 出来的帧和 `tools\drawtest.exe` 的隔离渲染 |
| 换新立绘 | 把三视图放到 `content\` 下，跑 `tools\make-sprites.exe <三视图> content\sprites "左范围,中范围,右范围"`；它会打印每个人裁自哪块，方便核对手脚有没有被切 |
| 想重新来过 | 删掉 `data\state.json`（好感度、位置、名字、设置全在里面，删了就当她刚认识你） |

`pet.log` 里会记：启动、DPI 缩放、台词库状态、第一次绘制结果、AI 请求与失败原因、快捷方式失败原因。

## 七、已知情况

- **桌面快捷方式**：第一次运行会试着在桌面创建 `娅娅桌面宠物.lnk`。如果程序被放在没有写权限的目录、或者你在受控沙箱里跑，这一步会失败并写进日志（软件本身照常用；设置窗里也有一键创建按钮）。测试时可以用环境变量 `YAYA_SHORTCUT_DIR` 指定输出目录来验证这段代码。
- **多显示器**：她在哪块屏幕上就在哪块屏幕活动，溜达范围是主屏工作区；拖到屏幕边缘会被挡住 35% 左右，免得拖丢。
- **DPI**：程序声明了 DPI 感知，150% 缩放的屏幕上她也是清晰的（字号不会二次放大）。
- **⚠ 改绘制代码时的坑（踩过一次）**：GDI+ 在 150% 缩放的机器上，`Graphics.DrawImageUnscaled` / 带 DPI 的绘制会按 `目标DPI/图片DPI = 1.5` 把图**放大后再裁掉**——表现就是「人物只剩一半、只剩一个大头」。所以：
  - 画到分层窗口缓冲区位图时，缓冲区要 `SetResolution(96,96)` 且 `PageUnit = Pixel`（见 `LayeredWindow.EnsureBuffer`）
  - 读立绘 PNG 时用**逐像素整块拷贝**，不要用 `DrawImage/DrawImageUnscaled`（见 `Sprite.LoadPng`）
  - 改完用 `tools\drawtest.exe`（隔离渲染）和 `娅娅桌面宠物.exe --dump`（实际帧）各出一张图，再用 `tools\bbox.exe` 比行分布，能立刻看出画对没画对
- **不会做的事**：不联网（本地词库模式下完全离线）、不采集你任何输入内容、不读你的文件。挂机判断只用系统「多久没碰键鼠」这一个时间戳。

## 八、分享给别人

跑一次 **`tools\make-package.bat`**，`dist\` 里会出现三样东西：

| 产物 | 大小 | 用途 |
|---|---|---|
| `娅娅桌面宠物-v1.0.zip` | ≈ 1.1 MB | **直接发给朋友**（微信 / QQ / 网盘 / U 盘都行） |
| `娅娅桌面宠物-v1.0-源码.zip` | ≈ 1.4 MB | 给懂技术、想自己改的人（含 `src` / `tools` / 台词素材 / README） |
| `dist\娅娅桌面宠物\` | — | 压缩包里那个文件夹本身，可以先自己点开试跑 |

**对方怎么用**：解压到任意文件夹（会得到一个 `娅娅桌面宠物` 文件夹，别放 `C:\Program Files`）→
双击里面的 `娅娅桌面宠物.exe` → 第一次运行自动在桌面建快捷方式。

**对方需要什么**：Windows 7 及以上。程序是 .NET Framework 4.x 的（Win 8/10/11 系统自带），
**不用装任何运行库、不用联网**（本地词库模式）。整个包就一个 exe + 台词库 + 4 张立绘。

**Windows 可能拦一下**：这个 exe 没有买数字签名，第一次运行可能弹「Windows 已保护你的电脑」→
点「更多信息」→「仍要运行」。如果是压缩包发过去的，让对方**先右键压缩包 → 属性 → 勾选「解除锁定」→ 确定，再解压**，就不会弹了。

**别把 `data\` 一起发**：那里面是好感度、位置、名字、设置（含加密后的 API Key）。
`make-package.bat` 已经自动排除，手工拷贝时注意别顺手带上（`data\state.json` 里的 Key 是 DPAPI
加密的、换台电脑解不开，但也没必要给）。

**想给她换个默认名字 / 台词**：改 `content\lines.json` 里的 `defaultName` 和对应分类，再跑一次打包
（**不用重新编译**，台词是运行时读的）。

**对方不想用了**：托盘图标右键 → 退出；删掉文件夹和桌面快捷方式；如果开过「开机自动启动」，
再删注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 里的 `YayaDesktopPet`。
`使用说明.txt` 里这些都写给对方看了。

**程序图标 / 版本信息**：`tools\build.bat` 会用 `content\sprites\pet-avatar.png` 自动生成
`app.ico`（7 个尺寸：16/24/32/48/64/128/256），一份编进 exe，另一份复制成 **`娅娅.ico`** 放在 exe 旁边；
右键 exe 属性能看到「娅娅桌面宠物 1.1.0.0」。

> **桌面快捷方式指向的是 `娅娅.ico` 这个独立文件，而不是 exe 内嵌图标**——这不是随便定的：
> Windows 外壳会按「图标路径」缓存图标，只换 exe 里的图标时它经常继续显示缓存的旧样子
> （尤其是之前渲染失败过、缓存成空白的情况）。指向一个新的 `.ico` 路径，外壳就必须重新读，图标立刻变新。
> exe 里仍然内嵌同样的图标，所以任务栏、alt-tab、文件本身也都是她的脸。

图标的样式（默认 `tile` = 她的脸 + 粉色圆角方块；挑样式时可以看 `make-icon --lab` 出的对比图）：

```bat
tools\make-icon.exe content\sprites\pet-avatar.png app.ico tile      :: 默认：脸
tools\make-icon.exe content\sprites\pet-front.png  app.ico body      :: 全身立绘版
tools\make-icon.exe content\sprites\pet-avatar.png app.ico circle    :: 粉色圆形底
tools\make-icon.exe --lab content\sprites\pet-avatar.png lab.png     :: 四种样式 + 小尺寸并排对比
```
换完样式要重新 `build.bat`（图标是编进 exe 的，同时会更新 `娅娅.ico`），再 `make-package.bat` 重新打包。

> **⚠ .ico 的坑（踩过）**：Windows 外壳对**小尺寸的 PNG 压缩条目**支持不稳定，会画成花屏或空白
> —— 表现就是「快捷方式图标很丑/是个空白方块」。所以 `MakeIcon` 里 **16~128 一律用传统 BMP(DIB) 条目**
> （32bpp BGRA + AND 掩码），只有 256×256 用 PNG 条目（微软官方也是这么做的）。

**桌面快捷方式的图标会自动更新**：程序每次启动都会检查 `桌面\娅娅桌面宠物.lnk`，
已存在就重写一遍（刷新图标和目标路径），没有且是首次运行才新建。
所以换了图标、或者把整个文件夹挪到别处之后，**只要重新打开一次程序，桌面图标就跟着更新**。
实在顽固的话：右键快捷方式 → 属性 → 更改图标 → 浏览到 `娅娅.ico`；或者桌面按 F5。

## 九、发到 GitHub（公开发布的注意事项）

面向公众发布时，这个仓库已经准备好的东西：

| 文件 | 作用 |
|---|---|
| `README.md` | **英文版** README（GitHub 默认展示，含截图、下载、编译、隐私、许可证） |
| `README.zh-CN.md` | 这个中文版（开发细节、排障） |
| `QUICKSTART.txt` / `使用说明.txt` | 给下载者的英文 / 中文快速上手（都在发布包里） |
| `LICENSE` | MIT（**只覆盖代码、台词、文档**；明确写了立绘不在范围内） |
| `ATTRIBUTION.md` | 立绘来源、作者、授权情况 + 「作者有异议立即移除」+ 给作者的确认话术 |
| `.gitignore` | 排除 `data/`（含加密的 API Key）、编译产物、打包产物、日志、三视图原图 |
| `docs/screenshot-main.png` | GitHub 首页用主图 |

**立绘的处理方式（已定）**：`content/sprites/` 是一张**来源不明的网传 AI 生成图**——
没有人类作者可署名，所以处理方式是「**带着它发布 + 把话说清楚**」：

- `LICENSE` 明确写了 **MIT 只覆盖代码、台词、文档**，立绘不在其中，别人拿不到商用授权
- `ATTRIBUTION.md` 写明：来源不明、不主张版权、**不建议商用**、**收到异议立即移除/替换**
- `tools\make-release.bat` 会自动把这两个文件打进发布包，并在结束时检查
  （缺 LICENSE 或 ATTRIBUTION 会直接报警）
- 想换成彻底干净的：删掉 `content/sprites/`（或取消 `.gitignore` 里那三行的注释）→
  程序自动改用 `content/placeholder/` 的原创占位形象（纯代码画的，随 MIT，可商用）

**打包命令**：

| 命令 | 产物 | 用途 |
|---|---|---|
| `tools\make-package.bat` | `dist\娅娅桌面宠物-v1.0.zip` | 发给朋友（中文文件名，带她的立绘） |
| `tools\make-release.bat` | `dist\YayaDesktopPet-v1.0-win.zip` + `-source.zip` | **挂 GitHub Releases**（英文名，含许可证/授权说明/文档截图） |

**双语支持**：设置里可切「中文 / English」，界面文案、台词库、AI 人格提示词全部跟着切。
两套台词库规模一致（各 95 分类 / 542 条），关键词匹配带词边界（`hi` 不会命中 `this`）。

**首次运行的礼貌**：程序会先问一句「要不要在桌面放个快捷方式」，不再不打招呼就往别人桌面放东西；
`--selftest` / `--dump` 这类无界面模式不会弹任何对话框。

**不适合进 git 的东西**：`dist/*.zip`（约 1.4 MB 的二进制）应当作为 **GitHub Releases** 的附件，
而不是提交进仓库；exe 同理。

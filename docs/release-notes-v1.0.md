# 娅娅桌面宠物 v1.0 / Yaya Desktop Pet v1.0

首个公开版本 · First public release

---

## 👉 三步就能玩（普通用户看这里）

1. **下载** 下面的 `YayaDesktopPet-v1.0-win.zip`
2. **解压** 到任意文件夹（桌面、D 盘都行；**别放 `C:\Program Files`**，那里程序存不了档）
3. **双击** 解压出来的 `娅娅桌面宠物.exe` —— 她就出现在屏幕右下角了

不需要安装、不需要运行库、不需要联网（本地聊天模式完全离线）。
第一次运行她会问一句「要不要在桌面放个快捷方式」，点「放一个」以后就能从桌面直接叫她出来。

> **如果 Windows 拦你**：这个 exe 没有买数字签名，首次运行可能提示
> 「Windows 已保护你的电脑」→ 点 **更多信息 → 仍要运行**。
> 想彻底不弹：**先右键下载的压缩包 → 属性 → 勾选「解除锁定」→ 确定，再解压**。
>
> 系统要求：**Windows 7 及以上**。

怎么玩：单击摸摸头 · 双击（或右键）出菜单 · 快速连点她会假生气 · 拖到哪她就住哪 ·
不理她 3 分钟她会来找你 · 菜单里可以投喂蛋糕、找个话题、和我聊天。

---

## 亮点 · Highlights

- **真·透明置顶**：逐像素 alpha 的分层窗口，她趴在壁纸和窗口上面；透明处鼠标点穿，不抢你打字时的焦点
- **摸得到的互动**：单击摸摸头 / 双击召唤菜单 / 1.2 秒点 4 下会假生气 / 拖到任意位置 / 鼠标靠近她会注意到你
- **她会自己溜达**：每 15–30 秒走到桌面别处（侧面姿势 + 朝向翻转 + 走路颠簸）
- **挂机分级**：3 分钟找你 → 5 分钟自己走开 → 8 分钟打瞌睡 → 12 分钟睡熟；你一碰键鼠她立刻醒
- **聊天两种模式**：本地词库（完全离线，85 分类 / 492 条）或任意 OpenAI 兼容接口的 AI 对话（记得住最近 12 轮）
- **中英双语**：设置里一键切换，界面文案 / 台词库 / AI 人格提示词全都跟着切
- **免安装、免运行库**：系统自带 .NET Framework 4.x 即可，压缩包约 2 MB
- **有礼貌**：第一次运行会先问一句「要不要在桌面放个快捷方式」，不会不打招呼就往你桌面放东西

## 隐私 · Privacy

- 本地词库模式：**完全离线**，不连任何服务器
- AI 模式：只把你打的那几句话发往**你自己配置的接口**，没有别的
- 不记录你输入的内容、不读你的文件、不监听键盘。判断你是否在电脑前只用系统提供的「最后输入时间」这一个时间戳
- 设置里的 API Key 用 **Windows DPAPI 按当前用户加密**后才写盘

# 娅娅桌面宠物 v1.1 / Yaya Desktop Pet v1.1

接上 API 之后，她不再只是"会聊天的桌宠"——互动也开始现场生成了。

---

## 🆕 这个版本新增了什么

### 1. 互动反馈也走 AI 了（本次最大的改动）

以前她摸头、投喂、做动作、挂机的时候，说的都是词库里那几句固定的。现在**接上 API 之后，这些互动会把"刚刚发生了什么"发给模型，让她现场说一句**。

- 点了她一下、喂了块蛋糕、跳了个舞、你 8 分钟没理她……反应都是现编的
- **本地台词仍然先说**，保证点下去立刻有反应；AI 那句是异步追加上来的，不会让你干等
- 只对 26 种"值得开口"的互动生效；走动、换姿势这类机械动作跳过，不会刷屏也不会刷 API
- 全局 15 秒冷却；失败或超时就静默放弃，体验不受影响
- 设置里可以关掉（只在 AI 模式下才有意义）

### 2. 记忆系统 —— 她记得住你

- 直接说 **「记住：我在备考」** 她就记下了（本地模式也认）
- AI 模式下，你聊天时提到的稳定偏好她会自己记住
- 以后聊天她会**自然地带出来**，不是硬背
- 想知道她记住了什么，问她 **「你记得什么」**；想让她忘掉，说 **「清空记忆」**
- 最多记 30 条，只存在你自己的 `data` 里

### 3. 节日与生日彩蛋

- **公历节日**：元旦、跨年夜、情人节、儿童节、国庆、万圣夜、圣诞
- **农历节日**：春节、中秋（用对照表，当前表到 2030 年）
- **你的生日**：跟她说一句「我的生日是 3 月 15 日」，到那天她会记得
- 台词库里新增 10 个节日分类、中英各 50 句

### 4. 久坐 / 熬夜提醒

- 连续用电脑 **50 分钟**，她会赶你起来活动
- 凌晨 **1 点到 5 点**还醒着，她会催你去睡（一晚只说一次）
- 中途离开满 5 分钟才算"休息过"，重新计时——所以她不会一直唠
- 隐私不变：判断依据**只有系统提供的「最后输入时间」这一个时间戳**，不记录按键内容、不读文件、不装钩子

### 5. 小游戏：猜拳 + 猜数字

在聊天窗里跟她说就行：

- 说 **「猜拳」** → 她说石头剪刀布你先出，你回「石头 / 剪刀 / 布」
- 说 **「猜数字」** → 她想一个 1–100 的数，你猜，她说大了还是小了
- 说 **「不玩了」** → 结束
- 中英文口令都认（`rock paper scissors` / `guess a number`）

## 🐛 修掉的问题

- **聊天记录最后一条气泡被切掉**：估算滚动总高和实际绘制用了两套算法，每条差 4×缩放像素，聊得越长偏得越多（AI 长回复时最后一条会整条看不见）。现在两边共用同一个函数，数学上不可能再算错
- **README 里的下载链接点了没反应**：原来用的是相对路径，在仓库首页解析出来是错的；已改成绝对地址

## 🔒 隐私（这一版没变，但还是说一遍）

- 本地词库模式：**完全离线**，不连任何服务器
- AI 模式：只把你打的话、和互动时的那一句情况描述，发往**你自己配置的接口**
- 不记录你输入的内容、不读你的文件、不监听键盘
- 设置里的 API Key 用 **Windows DPAPI 按当前用户加密**后才写盘
- 记忆和好感度都只存在 `data` 目录里，跟着你的电脑走
